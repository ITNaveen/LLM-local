# Music library

Drop royalty-free tracks into these mood folders. StoryMaker picks one per act:

| Folder | Used for |
|---|---|
| `dark/` | cold openings, threat, mystery |
| `tense/` | rising tension, countdowns |
| `emotional/` | struggle, sacrifice, the human side |
| `epic/` | the climax: big drums, choirs, goosebumps |
| `triumphant/` | victory, celebration, the ending |
| `calm/` | documentary build-ups, reflective endings |

**Safest source:** the free **YouTube Audio Library** (studio.youtube.com → Audio library).
Those tracks are cleared for YouTube, so they will not get Content ID claims. Search by
mood ("cinematic", "dramatic", "inspirational") and download 3–5 tracks per folder.

Avoid film songs and popular Bollywood music: those are the #1 cause of copyright claims.

Any track whose file name contains a mood word (e.g. `epic_battle_drums.mp3`) is also
picked up if you prefer one flat folder.
